# PF / circuit debate glossary

Debaters talk in shorthand. Read requests through this vocabulary. "Make me a case centered around a nuclear impact" means: choose a terminal impact of nuclear war, then build the link chain from the resolution to it.

## Argument anatomy
| Term | Meaning |
|---|---|
| **Uniqueness (UQ)** | The status quo: why the impact is not already happening, or why it is trending one way. "Growth is high now" is uniqueness for a recession argument. |
| **Non-unique (NUQ)** | A response saying the impact already happens (or won't happen) either way, so the resolution changes nothing. This is defense. |
| **Link** | How the resolution (or the other side's world) causes the change. |
| **Internal link (IL)** | The middle steps between the link and the impact. Chains break here most often. |
| **Impact** | Why it matters: deaths, poverty, war, rights. |
| **Terminal impact** | The final harm at the end of the chain (nuclear war, extinction, deaths, poverty). |
| **Warrant** | The reason a claim is true: the "because" inside the card. A card with a claim but no warrant is weak. |
| **Scenario** | One full link chain (for example, a Taiwan scenario). |
| **Contention (C1, C2)** | A main argument in a constructive. Sub-points are labeled A/B. |
| **Framework / FW** | How the judge should decide: a weighing lens such as util (maximize lives), structural violence, or probability first. |
| **Framing** | Pre-set weighing read in the constructive. |
| **Case** | The constructive speech: contentions plus cards. |
| **Aff / Pro, Neg / Con** | The sides. PF says Pro/Con, but "aff/neg" is common on the circuit. |

## Offense vs defense
| Term | Meaning |
|---|---|
| **Offense** | A reason to vote for you: your own impact or a turn. Only offense wins ballots. |
| **Defense** | Takes away their offense but gives you nothing: NUQ, delink, no-link, mitigation. |
| **Turn** | A response that flips their argument into offense for you. |
| **Link turn (LT)** | "The resolution actually *reduces* X." Their link runs the other way, so their impact now becomes yours. |
| **Impact turn (IT)** | "X is actually *good*." Their link stays, but the impact is reversed. |
| **Double turn** | Reading a link turn AND an impact turn on the same argument: "The res reduces X, and X is good." Together they mean the res reduces something good, which is offense for the *other* side. Never do it. The opponent will extend both and win. |
| **Delink / no link** | The resolution does not cause X. |
| **Mitigation / mit** | The impact is smaller than they claim. |
| **Terminal defense** | Defense that zeroes an argument completely (for example, a fully non-unique argument). |
| **Sticky defense** | Defense from first rebuttal that stays live in final focus even if summary didn't extend it. An old norm; many judges and leagues no longer accept it. Check with the judge. |
| **Pre-req / prerequisite** | "Our impact must be solved before theirs matters." |
| **Short-circuit** | "Our impact makes theirs impossible" (for example, extinction ends every other impact). |
| **Link-in / link into their impact** | Your argument also causes *their* impact. You access their weighing. |
| **Turns case** | Your impact causes their impact, so you win their impact too. |
| **Solvency** | Whether the proposal actually works. Used when the resolution is a plan-like action ("should enact a moratorium"). |
| **Alt causes / alternate causality** | Other things cause the impact, so the resolution won't fix it. |

## Weighing (impact calculus)
| Term | Meaning |
|---|---|
| **Magnitude** | How big the impact is (lives, scale). Extinction and nuclear war win magnitude. |
| **Probability** | How likely the chain is. It beats magnitude when the opponent's chain has many links. |
| **Timeframe** | How soon. A faster impact happens first and can short-circuit a slower one. |
| **Scope** | How many people are affected. |
| **Severity** | How bad the impact is for each person affected. |
| **Reversibility** | Whether it can be undone. Extinction and death are irreversible. |
| **Strength of link / clarity of impact** | Whose chain is better evidenced and clearer to the judge. |
| **Meta-weighing** | Arguing which weighing mechanism matters more ("probability comes before magnitude because..."). |
| **Weighing** | Comparing your offense to theirs. Weighing that is never done means the judge intervenes. |

## Speech and round terms
| Term | Meaning |
|---|---|
| **Constructive** | The first speech: reads the case. |
| **Rebuttal** | The second speech: responds to the opponent's case. In second rebuttal, the team must also frontline. |
| **Summary** | The third speech: collapses, extends and weighs. |
| **Final focus (FF)** | The last speech: the voting issues. Must mirror summary. |
| **Crossfire / CX** | Questioning periods. Crossfire, grand crossfire (all four debaters) and the final crossfire between the summary speakers. |
| **Frontline / FL** | Answering responses made against your own case. |
| **Block** | Pre-written responses to an expected argument (an "AT: X" block). |
| **Blockfile / block file** | A document of blocks. |
| **AT / A2** | "Answers to": an AT: Econ block. |
| **Extend / extension** | Carrying an argument into a later speech. A proper extension restates the claim, the warrant and the impact. |
| **Dropped / conceded** | The other side never answered it, so it is treated as true. Extend it and point out that it was dropped. |
| **Collapse** | Choosing one or two arguments to go for in summary and final focus, and dropping the rest. |
| **Kick** | Deliberately dropping one of your own arguments, which is safe only if it isn't turned. |
| **Cross-apply** | Using an argument from one place on the flow somewhere else. |
| **New in the 2** | A new argument in final focus (or second summary). It is illegitimate and judges ignore it. |
| **Off-time roadmap** | The order of the speech, given before the timer starts. |
| **Signpost** | Saying where you are on the flow ("on their C1..."). |
| **Flow** | Notes of the round, taken in columns by speech. |
| **Flow / lay / tech judge** | A flow judge is an experienced note-taker. A lay judge is a parent or community judge who is persuaded by clarity. A tech judge evaluates arguments by the flow and accepts theory/Ks. |
| **Prep** | Prep time, 3 minutes per team. |
| **Speaks** | Speaker points. |
| **Ballot / RFD** | The decision and the reason for decision. |
| **Bid / TOC** | A qualifying finish toward the Tournament of Champions. |

## Evidence terms
| Term | Meaning |
|---|---|
| **Card** | One piece of evidence: tag + cite + quoted text with the read parts marked. |
| **Tag** | A one-line claim the card proves, written by the debater. |
| **Cite** | Author, year and the full citation. The short cite ("Smith 24") is read aloud. |
| **Quals** | The author's qualifications. |
| **Underlining** | Text that gives context (not necessarily read aloud). |
| **Highlighting** | Text read aloud in the round. |
| **Cut a card** | Selecting the passage, marking it, and writing the tag and cite. |
| **Recut** | Re-marking an existing card, or re-tagging it for a new claim. |
| **Powertag** | A tag that claims more than the highlighted text proves. It is an indict opportunity against the other team and an ethics risk on your own cards. |
| **Clipping** | Claiming to read highlighted text that you skipped. It is cheating. |
| **Card clash / evidence comparison** | Why your card beats theirs: recency, quals, warrant, methodology. |
| **Indict** | Evidence or analysis attacking an opposing card or author. |
| **Speech doc** | A .docx of the cards read in a speech, shared by email chain or Speechdrop. |
| **Paraphrasing** | Summarizing the evidence instead of reading it. NSDA allows it with strict accuracy rules, but it is contested (see paraphrase theory). |
| **Disclosure** | Posting your case on OpenCaselist. |
| **OpenCaselist / caselist** | The site where teams disclose cases and round reports. |
| **Open source (OS)** | The full .docx posted to the caselist. |
| **OpenEv** | Camp evidence files released free on OpenCaselist. |
| **Evidence challenge** | A formal accusation of misrepresented evidence. It can end the round. |

## Progressive / tech PF
| Term | Meaning |
|---|---|
| **Theory / shell** | An argument that the opponent's practice is unfair: interpretation, violation, standards, voters. |
| **Disclosure theory** | "They must disclose on the caselist." |
| **Paraphrase theory** | "They must read cut cards, not paraphrase." |
| **IVI** | Independent voting issue: a standalone reason to drop the opponent (often evidence ethics or discourse). |
| **K / kritik** | Critiques the assumptions of the resolution or the opponent (for example, security K or cap K). Rare in lay PF. |
| **Trigger/content warnings** | A circuit norm to give these before graphic content. |
| **RVI** | A reason to vote for you because you won against their theory argument. Contested. |
| **Condo** | Conditional advocacy. Rare in PF. |

## Common shorthand
econ = economy · heg = US hegemony/primacy · prolif = nuclear proliferation · CCP / PRC = China · SCS = South China Sea · AI race / AI lead · xt = extinction · ev = evidence · 1AC/1NC-style labels (sometimes borrowed from policy) · "the res" = resolution · "the squo" = the status quo · "a2" = answer to · "t/" or "TL" = turn / link turn in flows · "DA" = disadvantage (sometimes used for a neg contention) · "adv" = advantage (an aff contention)
